# 2026 Rapid Acceleration

Robot Code for Team 4593 Rapid Acceleration | 2026 FRC Season: Rebuilt.

## Applications, Libraries, and Dependencies
- [WPILib](https://wpilib.org/): The foundational library for FIRST Robotics Competition programming. Handles the robot's functionality, including motor controls, sensors, and command scheduling.
- [WPILib Visual Studio Code](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html): A pre-configured IDE (VS Code) doptimized for FRC programming. Includes templates, debugging tools, and direct deployment to the RoboRIO.
- [Acceleration Station](https://github.com/TylerMueller08/AccelerationStation): A custom dashboard displaying real-time robot data and controls designed for driver control.
- [Advantage Kit](https://docs.advantagekit.org/): A framework for logging robot data for simulation and replay.
- [Advantage Scope](https://docs.advantagescope.org/): A robot diagnosis, log review/analysis, and data visualization application.
- [NI FRC Game Tools](https://www.ni.com/en/support/downloads/drivers/download.frc-game-tools.html#553883): Provides the official FRC DriverStation for controlling the robot, as well as ShuffleBoard and other tools.
- [PathPlanner](https://pathplanner.dev/home.html): A GUI-based tool for creating and fine-tuning robot paths for autonomous paths.
- [PhotonVision](https://photonvision.org/): Vision processing software for object detection and aligning with field elements during matches using AprilTags.
- [Phoenix Tuner X](https://v6.docs.ctr-electronics.com/en/2024/docs/tuner/index.html): Configuration and diagnostic tool for CTRE motor controllers and sensors, used to update CANivore and Kraken X60 motors.
- [Object Detection](https://github.com/TylerMueller08/Object-Detection-Pose-Estimation): A fast, robust, and field-ready algorithm for real-time object pose estimation in FIRST Robotics Competition (FRC) adapted from YoavRozov.
